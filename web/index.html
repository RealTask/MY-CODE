Features

Everything you need to code faster

From understanding your codebase to implementing complex features, MY CODE handles it all.

🤖

Intelligent Agent

Plans, executes, and reviews code changes with full context awareness. Understands your project's architecture and conventions.

🔍

Workspace Understanding

Automatically detects languages, frameworks, and project structure. Builds a semantic index of your codebase for intelligent context selection.

📁

Smart Context

Selects relevant files and symbols automatically. Manages token budgets efficiently to maximize AI effectiveness.

🛠️

Powerful Tools

Filesystem operations, terminal execution, search, git integration, and code analysis—all at the agent's disposal.

🔒

Security First

Permission system with approval workflows, sandboxing capabilities, and protection against dangerous operations.

💾

Sessions & Memory

Resume work seamlessly, track conversation history, and maintain project-specific knowledge across sessions.

🎨

Beautiful TUI

Polished terminal interface with streaming output, syntax highlighting, diff previews, and intuitive navigation.

🔌

Extensible

Plugin system for custom tools, providers, and commands. Build your own extensions or use community plugins.

🌐

Multi-Provider

Support for OpenAI, Anthropic, Google, and any OpenAI-compatible API. Switch providers or use local models.

How It Works

From idea to implementation

MY CODE follows a structured approach to understand, plan, and execute your requests.

1

Understand

Analyzes your request and scans the project to understand context, dependencies, and relevant files.

2

Plan

Creates a detailed implementation plan with step-by-step actions, considering best practices and project conventions.

3

Execute

Makes code changes using reliable patch application, runs commands, and performs necessary operations.

4

Verify

Runs tests, checks for errors, and validates changes. Automatically fixes issues when possible.
